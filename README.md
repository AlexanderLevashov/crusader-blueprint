# Stronghold Crusader Blueprint Mod

Интерактивный внутриигровой мод-оверлей чертежей замков для **Stronghold Crusader** и **Stronghold Crusader Extreme HD**.

Мод отображает пошаговые чертежи замков всех компьютерных лордов (Крыса, Змея, Кабан, Волк, Саладин, Ричард и др.) прямо поверх игрового поля в реальном времени с изометрической проекцией, подсветкой шагов строительства и автоматическим отслеживанием установленных построек.

---

## Основные возможности

- **16 компьютерных лордов и более 120 замков**: Читает оригинальные файлы `.aiv` из папки игры с помощью встроенного парсера движка. Доступны все вариации замков (варианты 1–8 для каждого лорда).
- **Пошаговое строительство (Step Focus)**: Выделяет точное место для следующей постройки, рисует динамические угловые рамки и плавающую плашку-указатель (`★ PLACE HERE: <Здание> (Step X) ★`).
- **Призрак всего замка (Ghost Castle Preview)**: Полупрозрачный контур будущей крепости для предварительного планирования стен, башен и экономики.
- **Умное авто-продвижение**: Автоматически сканирует сетку карты игры (`0x1a93208`, `0xf98606`) и переключает шаг строительства сразу после того, как вы разместили требуемое здание.
- **Поддержка тренировочных площадок (Training Ground / YARD)**: Территории возле военных казарм, гильдий инженеров/подкопщиков и коптилен нефти выделяются как `YARD` и автоматически засчитываются при постройке здания.
- **Свободная камера и фиксация на земле (Ground Pinning)**: Прицельтесь в нужное место карты и зафиксируйте чертёж кнопкой `Y`. Чертёж останется привязанным к координатам ландшафта, а камера может свободно перемещаться.
- **Отсутствие конфликтов с горячими клавишами игры**: Все функциональные клавиши (`F1`–`F12`), занятые в Stronghold Crusader под внутриигровые насмешки (taunts), освобождены. Управление вынесено на свободные клавиши.

## Управление (Горячие клавиши)

| Клавиша | Функция | Описание |
|---|---|---|
| **`~`** | **Вкл / Выкл оверлей** | Показать или скрыть чертёж замка |
| **`[`** / **`Page Up`** | **Предыдущий шаг** | Вернуться к предыдущему этапу постройки |
| **`]`** / **`Page Down`** | **Следующий шаг** | Перейти к следующему этапу постройки |
| **`\`** | **Все шаги / Пошагово** | Переключение: показывать весь замок или только до текущего шага |
| **`K`** / **`Shift + K`** | **След. / Пред. Лорд** | Смена лорда (Крыса, Змея, Кабан, Волк, Саладин, Ричард и т.д.) |
| **`L`** / **`Shift + L`** | **След. / Пред. Вариант** | Смена варианта замка выбранного лорда (от #1 до #8) |
| **`T`** / **`Insert`** | **Режим прицеливания** | Следование за курсором мыши или фиксация по центру экрана |
| **`Y`** / **`Delete`** | **Фиксация на местности** | Зафиксировать чертёж на земле (камера летает свободно) |
| **`U`** | **Режим фокуса** | Весь замок призраком (Full Castle) или фокус на текущем шаге (Step Focus) |
| **`J`** | **Стиль графики** | Режим подсказок (Guided) или подробный классический стиль (Classic) |

## Быстрый старт (Готовый файл)

Если вы не хотите собирать мод из исходников:

1. Скачайте готовую библиотеку **`shfolder.dll`** (из вкладки [Releases](../../releases) или после сборки).
2. Поместите **`shfolder.dll`** в корневую папку игры **Stronghold Crusader** (рядом с исполняемым файлом `Stronghold Crusader.exe` или `Stronghold_Crusader_Extreme.exe`).
3. Запустите игру. Оверлей активируется автоматически при старте игры.
4. При старте матча поставьте цитадель (Keep), выберите замок лорда клавишей `K`, настройте вариант клавишей `L` и стройте по шагам!

> **Как удалить мод**: Просто удалите файл `shfolder.dll` из папки с игрой.

## Сборка из исходников (Build from Source)

### Требования
- Компилятор **MSVC x86** (Visual Studio 2019 или 2022 с установленным компонентом *«Разработка классических приложений на C++»*).

### Процесс сборки
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/AlexanderLevashov/crusader-blueprint.git
   cd crusader-blueprint
   ```
2. Запустите скрипт сборки:
   ```cmd
   build.bat
   ```
   Скрипт автоматически найдет установленный компилятор Visual Studio, скомпилирует исходные файлы и соберет 32-битную DLL `shfolder.dll`.
3. Если репозиторий находится внутри папки игры (`<GameRoot>\Blueprint`), скрипт `build.bat` автоматически скопирует собранную библиотеку на один уровень выше прямо в корень игры.

## Как устроен мод изнутри

### 1. Перехват загрузки DLL (DLL Proxying)
Игра *Stronghold Crusader* при запуске динамически загружает системную библиотеку Windows `shfolder.dll`. По стандартным правилам поиска DLL в Windows, сначала библиотека ищется в текущем каталоге приложения, и лишь затем в `C:\Windows\System32`.
Мод экспортирует оригинальные функции `SHGetFolderPathA` и `SHGetFolderPathW`, перенаправляя их в системный вызов, и создает отдельный поток для отрисовки графики и взаимодействия с игрой.

### 2. Чтение данных из памяти игры
- **Цитадель игрока**: Определяется по базовому адресу структур зданий (`0xf98606`) и смещениям игрока (`0x115be90`).
- **Сетка карты**: Состояние тайлов (построено / пусто) считывается напрямую из таблицы карты (`0x1a93208`).
- **Смещение камеры**: Вычисляется из внутренних пиксельных координат скролла мира (`0x115be90` / `0x00f98600`).

### 3. Парсер AIV
Мод вызывает встроенную функцию движка Stronghold Crusader (`0x475690`) для загрузки файлов `.aiv`, извлекая сетку построек (`0x018a5b70`) и сетку очередности шагов (`0x018aa990`).

```
crusader-blueprint/
├── main.cpp          # DllMain, экспорт SHGetFolderPath, поток инициализации

├── blueprint.h       # Заголовочный файл менеджера чертежей

├── types.h           # Идентификаторы построек, цвета, английские имена
├── build.bat         # Скрипт сборки MSVC x86
└── README.md         # Документация проекта
```
